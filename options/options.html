Sync
Sync uses your browser's sync account and you need to enable sync for extensions/add-ons in your browser's preferences before enabling it here. The browser controls when data is actually synced and modifications on different devices might get lost if they happen over a short period.
Comment string

You can define your own comment string here. Everything after and including this string will be removed from items (but still matched against in autocomplete) before filling an input field e.g. only example item would be inserted for this item: example item // comment string if // is set as comment string.

If you include the word strftime after the comment string, format codes will be expanded on insertion e.g. %Y-%m-%d // strftime will be inserted as 2026-05-03.
Supported format codes:

  • %A - full weekday name
  • %a - abbreviated weekday name
  • %B - full month name
  • %b - abbreviated month name
  • %d - day of the month, zero-padded
  • %H - hour, 24-hour clock, zero-padded
  • %I - hour, 12-hour clock, zero-padded
  • %m - month, zero-padded
  • %M - minute, zero-padded
  • %p - am or pm
  • %S - second, zero-padded
  • %y - two-digit year
  • %Y - four-digit year
